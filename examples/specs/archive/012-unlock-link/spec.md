# 012-unlock-link: Разблокировка по ссылке из письма
Статус: done
Основа: feature:007-login-lockout

## Контекст

Заблокированный пользователь не может войти, пока не закончится блокировка.

## Границы

### Входит

- пользователь может разблокировать аккаунт по ссылке из письма о блокировке

### Не входит

- разблокировка через поддержку

## Решения

- ссылка действует 1 час. Причина: короче самой блокировки.
