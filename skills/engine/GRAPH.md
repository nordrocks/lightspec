# Граф SDD

Команда `graph` показывает связи сущностей в браузере. Для людей: скилы её не запускают, файлы она не пишет.

```
python3 <папка скилов>/engine graph [<фича>] [--specs <путь к specs/>] [--port 8765] [--open] [--json]
```

- `<фича>` — путь к `spec.md` или папке фичи, `<ID фичи>` или `<номер>`. Нет — граф всего main
- `--json` — напечатать граф и выйти, без сервера
- страница перечитывает файлы раз в секунду и перестраивает граф, когда они меняются

## Режимы

| Режим | Что на графе | Вкладка 1 | Вкладка 2 |
|---|---|---|---|
| фича | части `delta/` фичи, задачи `plan` и блоки main, связанные с ними | «Изменения»: домены и части с ADDED, MODIFIED, REMOVED | «Связи»: задачи, требования, контракты, документация |
| весь main | все блоки main, действующие ADR и все фичи из `new/` и `archive/` | «Домены»: домены и их блоки | «Связи»: фичи, требования, контракты, документация |

## Столбцы

| Столбец | Узлы | Группы | Режим |
|---|---|---|---|
| Фичи | фичи | «в работе» — `new/`, «закрыты» — `archive/` | весь main |
| Задачи plan | задачи `plan` | — | фича |
| Требования | требования | домен | оба |
| Контракты | элементы контрактов | интерфейс | оба |
| Документация и проект | блоки `domain-docs`, `architecture`, `conventions`, `project-doc`, ADR | «поддомен `<домен>/<поддомен>`», «проект» | оба |

## Узлы

| Узел | Как выглядит |
|---|---|
| часть `delta/` | полоса цвета изменения: ADDED — зелёная, MODIFIED — синяя, REMOVED — оранжевая, название зачёркнуто |
| блок main, который фича не меняет | пунктирная рамка, пометка «не меняется». Скрывается переключателем |
| узел, на который ведёт ссылка, но которого нет | курсив, пометка «нет в main» |
| задача | «☑ выполнена» или «☐ не выполнена» |
| фича | статус `spec` |
| блок, удалённый из main | красная рамка, название зачёркнуто, пометка «удалён из main фичей X». Виден, только когда выбрана фича, которая его касалась |

Подпись под названием — сущность и `Тип:` элемента контракта.

## Связи

Блоки между собой:

| Связь | От → к | Откуда берётся |
|---|---|---|
| виден через контракт | требование → элемент | `Контракты:` сценария |
| использует модель | элемент → элемент | `Вход:`, `Выход:`, `Ошибки:`, `Данные:` и ссылки `contract:` в тексте |
| объясняет | блок документации → элемент | `Контракты:` блока |
| держится на ADR | блок документации или проекта → ADR | ссылки `adr:` в тексте |
| заменяет | ADR фичи → ADR | `Заменяет:` |

Задачи, режим фичи:

| Связь | От → к | Откуда берётся |
|---|---|---|
| реализует | задача → требование или элемент | `Реализует:` |
| документация | задача → части файла документации | `Документация:` |

Фичи, режим main. Связь «фича → блок» берётся из `delta/` фичи и `Источник:` блока в main:

| Связь | Когда | Как выглядит |
|---|---|---|
| владелец | фича закрыта, она в `Источник:` блока: её версия в main | сплошная |
| меняла раньше | фича закрыта, в main уже версия другой фичи | серый пунктир |
| меняет | фича в работе меняет блок | синяя |
| удалит | фича в работе удаляет блок | синий пунктир |
| удалила | фича удалила блок, его в main нет | красный пунктир |
| меняла, позже удалён | фича меняла блок, потом его удалила другая фича | красный пунктир |
| опирается на | фича → фича | `Основа:` |

Связь удаляемой части в режиме фичи — серый пунктир.

## Взаимодействие

- наведение или выбор узла подсвечивает его связи, остальное приглушается
- «только выбранное и его связи» — оставить на графе выбранный узел и узлы, связанные с ним напрямую
- «блоки, которые не меняются, но связаны с изменениями» — режим фичи: показать или скрыть блоки main без изменений
- адрес страницы — `#<вкладка>/<id узла>`: выбранный узел переживает перезагрузку

## Панель узла

- сущность, файл, `Источник:`, у части `delta/` — `Причина:`, у задачи — «Файлы»
- «Связи» — каждая связь фразой со стороны узла: «реализует: AUTH-007», «изменён фичей: 012-unlock-link»
- «Нет в main» — у фичи: её части, которых в main нет, и почему: «удалила эта фича», «удалила фича X», «добавит при sync», «блока больше нет»
- «Текст» — часть в Markdown. Ссылки на узлы графа — кнопки. Диаграммы mermaid свёрнуты: «диаграмма mermaid — показать»

## JSON

`/graph.json` и `--json`:

| Поле | Что это |
|---|---|
| `mode` | `feature` или `main` |
| `feature` | `slug`, `title`, `status`, `path`. В режиме main — `main` и путь к `main/` |
| `nodes` | узлы, поля — ниже |
| `edges` | `from`, `to`, `kind` — вид связи, `removed` — рисовать пунктиром |
| `version`, `page` | отпечатки файлов и страницы: по ним страница перестраивает граф и перезагружается |
| `error` | ошибка разбора. Страница показывает её и держит прошлый граф |

Поля узла:

| Поле | Что это |
|---|---|
| `id` | `req:<ID требования>`, `contract:<ID элемента>`, `adr:<ID ADR>`, `doc:<файл>#<блок>`, `head:<файл>`, `task:<номер>`, `feature:<ID фичи>`, `gone:<id блока>` |
| `label`, `kind`, `column`, `group`, `domain`, `file` | подпись, сущность, столбец, группа в столбце, домен для вкладки 1, файл от `main/` |
| `action` | ADDED, MODIFIED, REMOVED или нет |
| `type`, `props`, `text` | `Тип:` элемента, свойства, текст части |
| `source`, `reason`, `owner` | у части `delta/`: `Источник:`, `Причина:`, скил-владелец |
| `done`, `files` | у задачи: выполнена ли, пункты верхнего уровня |
| `status`, `gone` | у фичи: статус `spec`, части `delta/` вне main |
| `missing` | узла, на который ведёт ссылка, нет |
| `removed_block`, `version`, `by` | у удалённого блока: признак, фича, чья версия показана, фича, которая удалила |
